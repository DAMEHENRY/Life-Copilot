# quant — The Quant Arsenal

## Purpose
Quant interview prep, portfolio projects, career assets, academic work, and historical XP artifacts. Everything here compounds Henry's quant career value, but v4.3 general life planning starts from `life-board.md`, not this folder.

## Accepts
- XP mission guides, session notes, derivations, code scaffolds (→ `arsenal/`)
- Active project files for Life Copilot and engineering builds (→ `projects/`)
- Interview prep, networking CRM, resumes (→ `career-moats/`)
- Academic coursework and UIBE obligations (→ `university/`)
- Datasets and raw data files (→ `data/`)
- Quant-related reference notes that don't fit arsenal format (→ `notes/`)
- Resume PDFs and drafts (→ `resumes/`)
- Daily and weekly schedules (→ `schedules/`)
- Root-level tracking files: `roadmap.md` (historical complete roadmap), `state.md` (legacy/manual Quant state), `career-vision.md`

## Rejects
- Personal diary or journal entries (→ `journal/`)
- General-purpose learning resources not tied to a quant goal (→ `resources/`)
- Completed or obsolete projects (→ `archives/`)
- Copilot prompt templates (→ `templates/`)

## Subfolders
| Folder | Contents |
|---|---|
| `arsenal/` | XP artifacts: mission guides, summaries, session notes, derivation guides, Python scaffolds |
| `projects/` | Active builds (Life Copilot, engineering scripts) |
| `career-moats/` | Interview prep, networking, career strategy |
| `university/` | UIBE academic obligations |
| `data/` | Datasets and raw data |
| `notes/` | Loose quant reference notes |
| `resumes/` | Resume files |
| `schedules/` | Daily/weekly schedules organized by `YYYY/MM/` |

## Create-New-Folder Rule
Only create a new subfolder if 5+ files share a clear category not covered above. Otherwise put files in the closest existing subfolder or at the root.

## Active / Important Files
- `roadmap.md` — historical quant leap roadmap with XP checklist
- `state.md` — legacy/manual quant mode state
- `career-vision.md` — long-term career direction
- `arsenal/xp-XX-*.md` — all XP mission artifacts
